# DeskPlant 结果盆栽

鸡蛋果采用紫皮百香果（Passiflora edulis）。鸡蛋果、蓝莓和草莓由内置 ImageGen 生成，菠萝、金桔和矮生小番茄由 Figma AI 绘制。 [新版菠萝素材](https://www.figma.com/design/HVftj9R3IA5YpCQaHNPVI2?node-id=5-3)

## 阶段和动画

| 植物 | 阶段图从左到右 | 动画样式 |
| --- | --- | --- |
| 鸡蛋果 | 幼苗 → 攀藤 → 开花 → 结果 | 藤蔓绕入土点慢摆，果实绕上端果柄摆动。花落后显示青果，逐渐长大并过渡到紫皮熟果。 |
| 菠萝 | 叶丛 → 抽花 → 青果 → 成熟 | 花序和果实共用叶心的果梗锚点。采摘动画和仓库使用去掉长果梗的熟果。 |
| 蓝莓 | 幼株 → 铃花 → 青果 → 蓝果 | 两簇铃花沿枝条轻晃。青果和蓝果沿用相同的位置，两串果实错开摆动节奏。 |
| 草莓 | 幼苗 → 展叶 → 开花 → 结果 | 白花从叶丛里长出，青果逐渐变红，两颗果实作为一组，绕共用果柄轻晃。 |
| 金桔 | 幼株 → 开花 → 结果 | 果园中青绿椭圆果长成橙色熟果。 |
| 矮生小番茄 | 幼苗 → 展叶 → 开花 → 结果 | 果园中绿色果串变红，每次采收三颗。 |

摆动可从叶丛 ±2°、4–5 秒一周期开始，菠萝叶丛幅度减半。鸡蛋果、蓝莓和草莓的花果可沿用枝叶的整体变换，再绕各自果柄增加约 ±3° 的摆动。花盆保持固定。

## 素材用法

- `*-stages.png` 是已合成的透明 PNG。每格 512 × 544，花盆底部对齐，适用于 DeskPlant 的横排阶段图读取逻辑。
- `*-parts.png` 是供果园使用的部件图集。使用 `layers.json` 中各品种的裁切矩形，图集的尺寸和部件位置可随品种变化。
- `layers.json` 的 `crop` 是原始图集的像素坐标，顺序为左、上、宽、高。 `pivot` 是裁切区域内的归一化锚点。 `at` 和 `width` 指 256 × 272 合成画布上的锚点坐标和显示宽度。绘制时等比缩放，先画花盆，再按阶段里的顺序画其他层。
- `alphaMin` 可用于清除图集中的低透明度杂色。 `unripe` 给出了没单列青果阶段的三种植物在转熟之前使用的青果位置。
